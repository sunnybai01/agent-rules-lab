# Jira

## Comments and links

Name the key in the branch and the pull request title.

Work that is not a feature needs no issue: a refactor, a fix found in passing, a tool, CI or a document. Its title has no key, its body says `Refs: none (<reason>)`, and its branch is `<type>-<short-name>`. A `feat` always names its issue, so that each acceptance criterion of an Ending has its pull requests. A change that builds part of an issue or an ID names that issue.
