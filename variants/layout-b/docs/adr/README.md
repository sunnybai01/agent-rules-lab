# Architecture decision records

An ADR records one decision that changes a module boundary, a contract, the data model or the technology. Write the ADR before the code.

## How to write an ADR

1. Copy [0000-template.md](0000-template.md) to `NNNN-short-title.md`. Use the next free number.
2. Fill every section. Cite Discovery IDs from [discovery-baseline.md](../discovery-baseline.md) and TD numbers from [technical-decisions.md](../technical-decisions.md). Do not invent IDs.
3. Set the status to `Proposed`. A person sets it to `Accepted`.
4. Add a row to the index below.
